Pokud chceme, aby nějaký text vystoupil oproti ostatnímu, máme několik možností jak to udělat. Pokud použijeme HTML máme funkce jako <strong>bold </strong> a nebo <em>Italicized</em>. Pomocí css můžeme nastavit background-color: yellow; nebo color:blue;

Většinou důležitá slova jsou **bold** a například latinské názvy, či jiné názvy jsou *italicusem*

Bold se v html nazývá strong, jelikož chceme tomu textu přidat sílu. Tohle už zabíhá do lingvistiky, ale dává to smysl

Italicus se na druhou stranu nazýva em neboli emphasize neboli vyzdvihnout. Ale pokud chceme přidat jenom lehkou nuanci (jemnost), odlišit text a lehce říct: tohle je něco odborného.
