Existují hlavní typy obrázku

JPEG
-fotky, které mají hodně barev
GIF
-Animované obrázky, nebo loga s málo barvami, ale svg je lepší
PNG
-Ideální pro obrázky s transparentnímí pixely
SVG
-V je jako Vektor, takže obrázky, které se přibližují a oddalují neztratí kvalitu. Ideální pro loga
