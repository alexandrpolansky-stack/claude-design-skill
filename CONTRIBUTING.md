# Jak přispívat

Pravidla pro přidávání znalosti jsou v **[CLAUDE.md](CLAUDE.md)**. Platí pro člověka i pro Claude,
proto jsou tam a ne tady: Claude Code si `CLAUDE.md` v repu načte sám, takže kdo v repu pracuje
s Claudem, dostane ta pravidla bez toho, aby na ně musel odkazovat.

Tenhle soubor je jen ukazatel, ať nevzniknou dvě verze pravidel, které se rozejdou.

## Zkratka pro nedočkavé

1. **Jen grafika a design.** Terraform, Jira, Python a firemní procesy sem nepatří, ani „když se to
   taky hodí". Důvod a tabulka hranic: [CLAUDE.md](CLAUDE.md), sekce HARD pravidlo.
2. **Jedna nota = jedno téma**, ASCII kebab-case jméno souboru, obsah česky.
3. **Zapiš notu do [`_index.md`](_index.md)**, jinak ji nikdo nenajde.
4. **Relativní markdown odkazy**, žádné Obsidian wikilinky `[[...]]`.
5. **Před pushem projeď kontrolu odkazů**, příkaz je v [CLAUDE.md](CLAUDE.md).

Repo je zdroj pravdy pro skilly. Neupravuj obsah v Obsidian vaultu a nečekej, že se to propíše.

Co je v knihovně hotové a co jsou mezery: [STATUS.md](STATUS.md).
